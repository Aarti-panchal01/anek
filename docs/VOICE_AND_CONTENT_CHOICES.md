# Voice and content choices

## Voice choice

- **Clone my voice** uses the speaker audio from the uploaded video after the recorded consent phrase is accepted. The voice is then used for generated speech.
- **Gnani AI sample voice** uses one of the available stock voices. You can choose and preview a voice before dubbing. This option does not require clone consent.

## Content type

The content type chips pass a tone preset into translation. They help the translator shape wording for the selected material. They do not change the selected voice, add speakers, or change the source audio. Available choices are Lecture, Explainer, Podcast, Sports, and Business.

## Translation style

- **Natural** is the recommended everyday style. For Indian language outputs, English loanwords should be written in the selected language's script.
- **Pure** uses formal, more fully native wording. It can produce longer speech, so more clips may need timing fixes.

Changing the style on an existing project asks for confirmation with the eligible clip count and estimated credit cost. Edited, locked, and verified clips are skipped. The scheduler is run again for clips that are re-translated.
